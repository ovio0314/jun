# 전표 계정과목 도우미 (1단계)

회계팀 전표 검토 공수 절감 도구의 1단계입니다. 로컬 PC에서만 동작하며 외부 AI/OCR/API를 호출하지 않습니다.
결재·반려·자동 분개 수정·ERP 쓰기 기능은 **없습니다**.

## 1단계 범위

1. **계정과목 현황** — 영림원 ERP 전표조건검색 엑셀에서 차변·대변에 쓰인 계정과목을 모두 파악
   - 계정코드/계정명별 차변·대변 행수, 합계(Decimal), 사용 전표 수, 사용구분(차변 전용/대변 전용/양쪽)
   - 비용구분·기표부서·적요 상위 예시, 상대계정(같은 전표 반대편 계정), 계정별 관리항목 사용 현황
   - 코드↔계정명 1:1 불일치 목록, 엑셀 다운로드(수식 주입 방지)
2. **계정 질문하기** — 전표 작성자가 "공장 전기요금 낼 때 차변 대변 뭐 써요?"처럼 물으면
   - 제조업 거래유형 가이드(47종)에서 해당 분개(차변/대변)를 제시하고, 제조(공장·생산)/판관(본사·영업) 맥락에 맞는 분개를 우선 표시
   - 불러온 전표 파일에서 회사가 실제로 쓰는 계정코드(일치/동의어/유사), 비슷한 적요의 과거 처리 사례, 질문에 언급된 계정의 상대계정을 함께 표시
   - 답변은 **일반기업회계기준 제조업 관행 참고**이며 회사 승인 규칙이 아닙니다.
3. **파일 요약** — 행 수, 전표 수, 기간, 차대변 불일치 또는 추출 누락 확인 건수, 파일첨부여부 값 구분

전표별 검사(금액/계정/적요/증빙 상태 모델, 검토상태·메모, 결과 저장/재열기)는 다음 단계입니다.

## 실행

```bash
cd voucher_review
pip install -r requirements.txt
streamlit run app.py                    # http://127.0.0.1:8501 (로컬 전용, .streamlit/config.toml)
python -m pytest -q                     # 테스트
python sample_data/make_synthetic.py    # 익명 합성 샘플 엑셀 생성 (시연용)
```

실제 파일은 `voucher_review/input/` 또는 저장소 루트 `input/` 에 두면 사이드바에서 선택할 수 있습니다(예: `input/9월 전표 내역.xlsx`).
`input/`, `output/`, `local_data/`, 모든 `.xlsx/.csv` 는 `.gitignore` 로 제외됩니다.

> **검증 상태:** 실제 파일 `input/9월 전표 내역.xlsx` 는 개발 환경에 없어 **실제 파일 검증은 하지 않았습니다.**
> 설명된 46개 열 구조(첫 행 제목, 둘째 행 헤더)의 익명 합성 데이터로만 테스트했습니다.
> 참고값(1,224행 / 276 기표번호 등)은 화면에 하드코딩하지 않고 파일에서 계산합니다.

## 처리 기준 (보수적 기본값)

| 항목 | 기준 |
|---|---|
| 헤더 인식 | 모든 시트 상단 30행에서 예상 열 이름이 5개 이상 일치하는 행을 후보로 제시, 사용자가 선택 |
| 필수 열 | 회계단위, 전표관리단위, 기표번호, 계정과목코드, 계정과목, 차변금액, 대변금액 (누락·중복 시 한글 오류) |
| 전표 키 | 회계단위 + 전표관리단위 + 기표번호. 전표기표번호는 분개 행 식별자, 원본 엑셀 행번호(`_엑셀행`) 유지 |
| 문자열 보존 | 번호·계정과목코드·사업자번호는 문자열. 공백 정리 전 원본은 `raw` 표에 별도 보관 |
| 금액 | Decimal. 쉼표·공백·'원' 제거, 음수(`-`, `△`, `▲`, 괄호) 허용. 해석 불가 값은 0으로 바꾸지 않고 **금액오류**로 분리·합계 제외 |
| 빈 금액 | 합계에서 0으로 봄(ERP는 한쪽만 입력). 빈값 여부는 `*_상태` 열에 보존 |
| 차대 구분 | 차변금액만 → 차변, 대변금액만 → 대변, 둘 다 → 차대동시, 둘 다 0/빈값 → 금액없음 |
| 외화 | 원화 합계에 더하지 않음 |
| 파일첨부여부 | 문자열 TRUE/FALSE·불리언·빈값 구분 표시만. FALSE 를 증빙 누락으로 판정하지 않음 |
| 관리항목 | 계정별로 의미가 다르므로 계정 단위로만 사용 현황 표시(관리항목2를 공급가액으로 가정하지 않음) |
| 차대 불일치 | '차대변 불일치 또는 추출 누락 확인'으로 안내(필터된 불완전 전표 가능성) |
| 모집단 | 파일 전표 수와 업무상 750~800건(집계 기간 미확인)을 같은 모집단으로 가정하지 않음 |

## 계정 가이드 수정

- 기본 가이드: `voucher/data/manufacturing_guide.json` (거래유형·키워드·분개·해설·주의·동의어)
- 화면 **⚙️ 안내·설정** 에서 JSON 다운로드 → 회사 기준으로 수정 → 업로드(세션 적용 또는 `local_data/account_guide.json` 저장)
- 저장된 회사 가이드는 확인 체크 후 별도 버튼으로만 삭제됩니다. **초기화** 버튼은 현재 세션만 비우고 원본 파일·저장 데이터는 지우지 않습니다.
